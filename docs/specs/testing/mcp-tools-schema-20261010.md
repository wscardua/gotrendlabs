Esta alteração adiciona hashes independentes de checklist e modelo à resposta `get_editorial_policy`; preserva `version=1.2` e o hash da política aprovada. A suíte **local** `tests.test_mcp_editorial tests.test_mcp_adapter` passou com 56 testes em PostgreSQL isolado, incluindo cliente Streamable HTTP com serviço e OAuth, `tools/list`, respostas, rejeição de campos antigos, preservação de URL/evidência na migração e bloqueio de aprovação com pendências. Após reforçar as verificações dos caminhos `record` e do schema de política, o teste integrado foi repetido e passou (1 teste, 18,226 s). O snapshot OpenAPI passou em `--check`, assim como Django `check`, compilação Python e `git diff --check`. Os novos hashes só estarão na resposta produtiva após implantação desta alteração. A conexão `MyGoTrendLabsMCP-v2` ainda precisa de atualização de metadados e reteste no cliente; não foi possível acioná-la nesta sessão.
